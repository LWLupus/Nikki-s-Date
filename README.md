## HOW THIS WAS MADE

This was made using vite and three.js also the main tutorial I used to learn three.js was fireship's three.js video.

## heres how to run the project :)
1. Clone the source code to your device
```sh
git clone https://github.com/LWLupus/Nikki-s-Date.git
```

2. Install the project's dependencies
```sh
npm install
```

3. Start the development server on `localhost:4321`
```sh
npm run dev
```

4. Build the site to `/dist`
```sh
npm run build
```
This should be all.
